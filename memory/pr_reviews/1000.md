## Findings

### F1: Seek clamp turns skip forward into a jump back once playback passes the estimated duration  (fixed)

- **severity:** Warning
- **status:** fixed
- **location:** PodHaven/Play/PlayManager+PlaybackControls.swift:22 (scope: in-diff)
- **concern:** The On Deck duration is AVFoundation's estimate, which playback can run past (VBR or ad-stitched audio), so clamping every seek to it sent a skip forward from beyond the estimate back to the estimated end.
- **resolution:** Seeks clamp to the duration only while playback hasn't passed it; past it, only the start bounds a seek. A new test plays past a 4:00 estimate and shows skips forward and back move relative to the real position.
- **fixed_at:** 2026-11-09

### F2: Widget intent rethrows a superseded load's cancellation as failure  (skipped)

- **severity:** Nit
- **status:** skipped
- **location:** PodHaven/Widget/Intents/PlayEpisodeIntent.swift:38 (scope: in-diff)
- **concern:** A newer playback request that supersedes the intent's load throws `CancellationError`, which the intent now rethrows, while a `.superseded` result returns success.
- **resolution:** Widget button taps show nothing for intent errors, so only a manual Shortcuts run racing another playback request could surface it; the PR body accepts that intent errors propagate, and the inconsistency doesn't justify more branches.
