### F4: Symbolic queries collapse to over-broad prefix  (skipped)

- **status:** skipped
- **location:** PodHaven/Database/Models/Episode.swift:261 (matchesText)
- **concern:** FTS unicode61 drops `#`/`+`; "C#"/"C++"/"F#" tokenize to a 1-char prefix (c*/f*) → floods results, vs old LIKE's literal `%c#%`. Distinct from F3 (real token vs nil).
- **resolution:** accepted as inherent FTS tradeoff (matches F3 disposition, PR's speed goal); symbolic-name search is rare. Alternative noted: LIKE fallback for <2-char tokens.
