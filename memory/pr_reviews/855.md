## Findings

### F1: Re-parsing an unchanged feed no longer yields an equal UnsavedPodcast  (skipped)

- **severity:** Nit
- **status:** skipped
- **location:** PodHaven/Feed/Models/PodcastFeed.swift:302 (scope: in-diff)
- **concern:** `UnsavedPodcast`'s synthesized `Hashable` now includes a per-parse `lastUpdate`, so the `statesEqual` short-circuit in `PodcastDetailViewModel.transition` and share navigation path values never match across re-parses of an unchanged feed.
- **resolution:** Skipped. The cost is a redundant episode-list projection and filter refresh on a user-initiated pull-to-refresh of an unsaved podcast (recommendation scoring hits its snapshot cache), or a rebuilt destination when the same share link opens twice; both already happen whenever the feed changes. Excluding `lastUpdate` from equality would add a custom conformance for no user-visible gain.
