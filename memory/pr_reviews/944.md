### F1: Refresh waits without a bound for the first network path  (skipped)

- **severity:** Warning
- **status:** skipped
- **location:** PodHaven/Environment/ConnectionState.swift:40 (scope: in-diff)
- **concern:** `currentPath()` has no timeout or fallback, so if the monitor never delivered its first update, every refresh in that process would stall silently until cancellation, where `main` refreshed with placeholder limits.
- **resolution:** `NWPathMonitor` delivers the current path within milliseconds of `start`, and `ConnectionState` now retains it on a dedicated serial queue.
