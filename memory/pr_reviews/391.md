## Findings

### F1: calculateCacheSize aborts whole purge on a vanished file

- **severity:** Warning | **status:** fixed
- **location:** PodHaven/Cache/CachePurger.swift:229 (calculateCacheSize)
- **concern:** calculateCacheSize sums fileManager.fileSize over directory contents and lets a missing-file throw propagate out of executePurge, aborting the entire purge — the same missing-file class this PR hardens in the size-purge loop, left unhandled in a sibling path.
- **outcome:** Wrapped the per-file fileSize in do/catch; missing-file (ErrorKit.isMissingFile) is logged at .debug and skipped, other errors rethrow. Added regression test executePurgeToleratesMissingFileDuringCacheSizeCalculation (red: executePurge threw NSCocoaError 260).
- **resolution:** hardened, consistent with loop behavior
- **fixed_at:** 2026-05-31

### F2: Redundant NSCocoaErrorDomain branch in isMissingFile

- **severity:** Nit | **status:** fixed
- **location:** PodHaven/Errors/ErrorKit.swift:53-58 (removed)
- **concern:** The NSError/NSCocoaErrorDomain code check is unreachable because any NSError with domain NSCocoaErrorDomain already casts to CocoaError and is caught by the preceding block, with identical codes.
- **outcome:** Removed the dead block; kept CocoaError + POSIX ENOENT + recursive underlying. Missing-file debug test still green, confirming CocoaError block catches NSCocoaErrorDomain NSErrors.
- **resolution:** dead-code removal, no behavior change
- **fixed_at:** 2026-05-31

### F3: Loop re-clears missing-file refs already cleared by validateCachedEpisodes

- **severity:** Nit | **status:** fixed
- **location:** PodHaven/Cache/CachePurger.swift:113-128 (in-loop clear removed)
- **concern:** Both validateCachedEpisodes and the size-purge loop run off the same stale cachedEpisodes snapshot, so every already-missing file was processed twice (a .notice from validate plus a .debug + redundant updateCachedFilename(nil) from the loop); root cause #388 asked about.
- **outcome:** Dropped the redundant in-loop updateCachedFilename(nil); loop now logs .debug + continue. validate handles the common case; next run reconciles any post-validate race (pre-PR behavior, still satisfies #388 done-criteria).
- **resolution:** removed redundant write; defensible tradeoff accepted by user
- **fixed_at:** 2026-05-31
