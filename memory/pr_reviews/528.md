- **concern:** exact overlap filtering rejects a replacement segment whose recomputed start falls just before the requested restart boundary
- **issue:** the old crossing phrase is removed, but its slightly earlier replacement is also filtered out

- **test_plan:** resume from a crossing segment whose replacement starts slightly before the logical restart and assert it survives exactly once
- **outcome:** replacement filtering now shares the checkpoint's timing tolerance, clamps its lower bound to zero, and requires overlap with the replaced range; a failing-first resume regression proves a source-frame-rounded replacement survives exactly once
- **status:** fixed
- **decision:** fix in this PR with timing-tolerant overlap replacement and a failing-first regression
