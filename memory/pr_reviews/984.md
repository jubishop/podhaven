### F2: A play before a newer load claims its transition joins the old load  (skipped)

- **severity:** Warning
- **status:** skipped
- **location:** PodHaven/Play/PlayManager.swift:610, PodHaven/Play/PlayManager.swift:164 (scope: in-diff)
- **concern:** While on-deck recovery holds another episode, `load()` awaits the recovery lookup after `play(C)` sets its pending play but before it claims the transition, so a `play()` in that window joins the old loading episode, overwrites C's pending play, and `play(C)` returns `.unavailable` with C paused.
- **resolution:** Skipped. It needs an active on-deck recovery, an in-flight load, and a selection and a play landing within one database read; before this PR the same window superseded C instead, so neither path served it. Closing it means claiming the transition before that await or tracking the claiming request, which changes load ownership for a vanishing race.
