### F1: Long descriptions change accessibility focus granularity (skipped)

- **severity:** Warning
- **status:** skipped
- **location:** PodHaven/Views/Components/DescriptionText.swift:9-16
- **concern:** Splitting a long description into native Text rows adds focus stops at block boundaries, potentially interrupting sentence-level reading.
- **resolution:** Skip. Only multi-block descriptions change; short content stays one row. Extra navigation is plausible, but no lost text, reordered content, or broken link action was demonstrated. Combining the entire long document removes block navigation and needs link/action regression validation: [Apple documents](https://developer.apple.com/documentation/swiftui/accessibilitychildbehavior/combine) that combining can transform or ignore child properties. That semantic and validation cost is not justified by the unproven benefit. Retain native rows and the accepted #712 validation scope; revisit only with evidence of a concrete accessibility failure.
