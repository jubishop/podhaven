## Findings

### F1: Pause mark outlives a later play during auto-advance  (fixed)

- **severity:** Warning
- **status:** fixed
- **location:** PodHaven/Play/PlayManager.swift:585 (scope: in-diff)
- **concern:** `pause()` marked the in-flight load transition paused, but `play()` never cleared it, so a pause then a play during the same auto-advance (an audio interruption that pauses and resumes, or a play from the widget, play bar, or lock screen) left the replacement paused, where `main` played it.
- **resolution:** `play()` resets the transition to automatic playback, so the latest request wins. The new test "a play after a pause before the next episode plays resumes it" failed in both advance phases before the fix and passes after.
- **fixed_at:** 2026-11-08

### F2: Pause in the hop after a load finishes is lost  (skipped)

- **severity:** Warning
- **status:** skipped
- **location:** PodHaven/Play/PlayManager.swift:761 (scope: in-diff)
- **concern:** The load task clears the transition before `advance` resumes, so a pause that runs in that one actor job boundary marks nothing, and `advance` still plays the replacement.
- **resolution:** The window is a single PlayActor enqueue. Every pause during auto-advance was lost on `main`, so this doesn't worsen anything. Closing it would need pause state scoped to the whole advancement, which costs more than the window justifies.

### F3: Toggle during a load can't request playback  (skipped)

- **severity:** Warning
- **status:** skipped
- **location:** PodHaven/Play/PlayManager.swift:667 (scope: in-diff)
- **concern:** Any in-flight load transition makes toggle pause, so a resume press during a load without pending autoplay (after an earlier cancel, or during a persisted restore) does nothing until the load ends.
- **resolution:** This is the cancel-on-toggle behavior the issue recommends. A play request that arrives after a load clears the deck is already dropped on `main`, one more press after the load recovers, and honoring it would need new post-load fulfillment state for bare loads.
