### F1: Existing partial podcasts never get series backfill on later saves (pending)

- **severity:** Warning
- **architecture:** true
- **location:** PodHaven/Database/Models/UnsavedPodcastEpisode+Series.swift:18-20
- **scope:** in-diff
- **concern:** alreadySaved treats podcast row existence as a complete series, skipping feed pull for partial podcasts
- **issue:** guard returns single-episode upsert when podcastSeries != nil, so 0- or 1-episode shells from prior failed/minimal saves never heal
