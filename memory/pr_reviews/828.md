## Findings

### F1: Advancing while playing never ends the background task  (fixed)

- **severity:** Warning
- **status:** fixed
- **location:** PodHaven/Play/PlayManager.swift `advance(to:autoAdvanceID:)`
- **concern:** `clear()` keeps AVPlayer's rate, so finishing while playing (lock-screen or CarPlay next, PlayBar or widget finish) starts the replacement during `.loading`. The later `play()` reports no new `.playing`, so the task stayed open until a later request or iOS expiration, which logged a false `autoAdvanceExpired phase=awaitingPlayback` warning.
- **resolution:** After recording `awaitingPlayback`, `advance` ends the advancement at once when the reported status is already `.playing`. A red-green regression test in `AutoAdvanceBackgroundTaskTests` covers it.
- **fixed_at:** 2026-11-04
