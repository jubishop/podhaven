### F2: Publisher lookup can stall otherwise-local transcription offline (fixed)

- **status:** fixed

- **outcome:** Publisher retrieval now uses a dedicated fast-fail session while feed refresh retains wait-for-connectivity behavior; a deterministic cached-audio regression proves the local fallback starts without releasing a held feed request.
