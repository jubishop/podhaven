### F8: Local-name matching accepts non-Podcasting transcript elements (skipped)

- **severity:** Warning
- **status:** skipped
- **location:** PodHaven/Feed/Models/PodcastRSS.swift:99
- **concern:** Matching only the `transcript` local name also accepts unqualified or unrelated-namespace elements instead of requiring the Podcasting 2.0 namespace URI.
- **resolution:** A collision needs a foreign transcript-shaped element and a valid timed payload, while enforcing namespace URIs with arbitrary prefixes requires a separate XML pass because XMLCoder hides them; the very-low expected harm does not justify that architecture.
- **source_thread_id:** PRRT_kwDONT4Ems6Vly-a

### F5: Alternate Podcasting namespace prefixes are ignored (fixed)

- **status:** fixed

- **concern:** The hard-coded `podcast:transcript` coding key silently ignores valid transcript elements that use another XML namespace prefix.
- **outcome:** RSS decoding now discovers transcript elements by namespace-local name, preserves malformed-element isolation, and avoids duplicate decoding of repeated keyed-container entries.
- **fixed_at:** 2026-07-31
