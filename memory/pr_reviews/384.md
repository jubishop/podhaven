## Findings

### F1: "Skip to next episode" stops instead of advancing when stop-after is on

- **severity:** Nit
- **architecture:** false
- **confidence:** low
- **location:** PodHaven/Play/PlayManager.swift:445-450 (interaction with PlayBarSheet finish button and command-center next-track at PlayManager+Events.swift:439-447)
- **description:** While "Stop After This Episode" is enabled, any explicit "skip to next episode" action also stops playback instead of advancing. The in-app finish button (`PlayBarViewModel.finishEpisode()`) and the lock-screen / AirPods next-track command (`.nextEpisode` → `finishEpisode()`) both route through `finishEpisode`, which hits the new stop branch and ends playback. A user who presses the forward/next control expecting to move to the next episode instead gets a stop, and on the lock screen there is no visible cue (the only indicator is the in-app moon icon).
- **evidence:** `finishEpisode` stop branch returns before the queue/recommendation advance logic; `finishOrJumpButton` calls `viewModel.finishEpisode()`, and `.nextEpisode` command maps to `await finishEpisode()`.
- **impact:** Potential UX surprise: explicit "next" gesture yields "stop." Behavior is uniform across all finish paths and is covered by tests (`stopAfterCurrentEpisodeStopsInsteadOfRecommendation` exercises the direct `finishEpisode` skip path), so this is very likely the intended product behavior.
- **recommendation:** Confirm intended. If intended, no change (the flag is meant to govern every episode-end transition, manual or natural). Alternative: treat an explicit manual skip as "advance now" and only stop on natural end — but that splits the finish path and complicates the contract.
- **alternatives:** Leave as-is (recommended); or only honor the flag on natural `didPlayToEnd`, advancing on manual skip.
- **decision:** Skip — intended behavior
- **decision_notes:** User confirmed the flag is meant to govern every episode-end transition (manual or natural). Consistent across all finish paths and already covered by tests.
