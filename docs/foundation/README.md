# Project Starter foundation

Shared pages managed by Project Starter. Its `bin/sync` replaces them with
each release, so do not edit them here. Put project-specific rules in project
pages and link to these; project rules take precedence wherever they differ.

- [Engineering policy](engineering-policy.md): dependencies, tests, file and
  page organization, checkout isolation, runtime versions, checks, and
  deployment.
- [Knowledge search](knowledge-search.md): search commands, failures,
  refreshes, home memory, worktrees, hooks, and diagnostics.

## Enabled features

This project enabled these optional Project Starter features.

- [Memory audit](memory-audit.md): the weekly Claude audit of memory notes,
  its schedule, settings, validation, publishing, and failure issue.
